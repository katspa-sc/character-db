# Static Word Searcher

This static project provides a simple word search interface powered by HTML, CSS, and JavaScript. It replicates the functionality of your Tkinter app in the browser.

## Usage

1. Place your `rzeczowniki.txt` file (one word per line) in the root of this directory.
2. Host on GitHub Pages or any static file server.
3. Open `index.html` in your browser.

The app will load the word list, filter by regex pattern (max word length 10), and allow you to click items to search on Google or copy the results to the clipboard.
