# Character Database

A static, client-side browser for a roster of characters across multiple fandoms. Search by name
(with Polish-phonetic matching), filter by fandom, and mark characters as *ignored* or *used* —
state is saved in your browser's localStorage.

## Usage

The app loads `data/characters.json` via `fetch`, so it must be served over HTTP (opening
`index.html` directly through `file://` will fail):

```bash
python -m http.server 8000   # then open http://localhost:8000
```

It works on GitHub Pages or any static file host — serve the repo root as-is.

## Rebuilding the data

Character rows and thumbnails are generated by the Python pipeline in `build/`:

```bash
cd build
python -m venv .buildvenv && source .buildvenv/bin/activate
pip install -r requirements.txt
python build_data.py
```

Re-running is safe — existing characters are skipped and only new ones are added. See `CLAUDE.md`
for how to add a new fandom.
